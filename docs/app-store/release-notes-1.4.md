## Заметки для ревью (App Review Notes)

```
Что изменилось в 1.4:

1. Rewarded-видео (AdMob). Пользователь по своему желанию смотрит ролик и
   получает 6 часов без рекламы. Награда выдаётся только после полного
   просмотра; закрытие ролика раньше времени награды не даёт. Отметка о
   награде хранится локально на устройстве и никуда не передаётся.
   Функция необязательная и дублирует уже существующую разовую покупку.

2. Политика конфиденциальности дополнена разделом о приложении — он
   объясняет сбор данных, задекларированный в анкете App Privacy: реклама
   AdMob, обработка покупки магазином и RevenueCat, обезличенные события
   интерфейса, обновление справочных данных.

3. Приложение работает офлайн: все расчёты выполняются на устройстве, история
   расчётов и избранное хранятся локально. Подключение нужно только для
   обновления справочных данных и курсов валют.
```
