## Review notes (App Store, при необходимости)

Bugfix release: the in-app updater could not fetch its update manifest since 1.4
(same-host request was intercepted by the local web server on Android and blocked
by CORS on iOS). Fixed by fetching the manifest through the native HTTP layer.
No new features, no new permissions, no changes to purchases or ads.
